# Политика безопасности

## Как сообщить об уязвимости

Пожалуйста, **не публикуй уязвимости в открытых issue**.

Сообщи приватно через [GitHub Security Advisories](https://github.com/vazonhub/bsuir-schedule/security/advisories/new) — только мейнтейнеры увидят отчёт.

Что важно указать:

- какие данные/функции затронуты;
- шаги воспроизведения или PoC;
- версия приложения и платформа.

Постараемся ответить в течение нескольких дней. После выпуска фикса уязвимость будет раскрыта в advisory с указанием репортера (если ты не против).

## Поддерживаемые версии

Фиксы безопасности выпускаются только для последней версии приложения в App Store / Google Play.
