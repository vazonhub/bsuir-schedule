# Fix Patch — план

Ветка: `fix/patch-review` (от `master`).
Правило: после каждого шага — коммит от лица пользователя (без co-author Claude).

## Зафиксированные решения (из вопросов)

- **Подгруппа в дневнике:** при выборе «Общая» (0) — блок подгруппы не показываем вовсе. Иконка — та же, что в `SubgroupPicker`.
- **Прошедшие пары в «ближайших»:** считать пройденной по времени **окончания** (`endTime < now`), идущая сейчас пара ещё показывается.
- **Заголовок «Расписание»:** только на вкладке обзора `ScheduleTabScreen` (над сегмент-контролом).
- **Обрезка `...`:** название факультета (заголовок секции) в одну строку; placeholder поля поиска обрезать.
- **Иконки Android:** подход 1 — весь квадрат уменьшить до пропорции эталона (`assets/android-icon.png`, ~56%) и поместить по центру на канву того же фонового цвета. Только Android, iOS не трогаем. У градиентных — допустим шов.
- **Виджет Android:** фон следует настройке темы в приложении (light/dark/system → resolve). Тему передаём в снапшот.
- **Google-аккаунт (Android):** только скрыть строку из UI настроек; код/плагин оставить.

### Шаг 2 — «Ближайшие»: скрывать прошедшие сегодня пары
- Файлы: `src/utils/diary.ts` (`extractUpcomingSubmissions`, ~105-125), при необходимости `scheduleNormalization.ts` (доступ к `endTime`/`startTime`).

- Не ломать day-granularity `remaining` счётчики без надобности (уточнить: применяем только к upcoming-списку).
- **Commit:** `fix(diary): не показывать в ближайших уже завершившиеся сегодня пары`

### Шаг 3 — Заголовок «Расписание» на вкладке обзора
