# Кодекс поведения

Проект следует [Contributor Covenant](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/), версия 2.1.

## Коротко

- Уважаем друг друга: доброжелательность, терпимость к разному опыту и точкам зрения.
- Конструктивная критика — да; переходы на личности, троллинг, харассмент — нет.
- Публикация чужих личных данных без разрешения недопустима.

## Область действия

Кодекс действует во всех пространствах проекта: issues, pull requests, discussions.

## Нарушения

О нарушениях сообщайте мейнтейнерам через приватную форму [Security Advisories](https://github.com/vazonhub/bsuir-schedule/security/advisories/new) или любым контактом из профиля мейнтейнера. Все жалобы будут рассмотрены.

Полный текст кодекса: [contributor-covenant.org (rus)](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).
