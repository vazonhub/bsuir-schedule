# DIARY_ONBOARDING_PLAN.md

План фичи: пошаговая обучалка (spotlight coach-marks) на вкладке «Дневник».

Ветка: `feature/diary-onboarding`. Каждый шаг плана = отдельный коммит (без Claude в co-author, всё от лица разработчика).

---

## 0. Продуктовые решения (зафиксированы с пользователем)

| Вопрос                     | Решение                                                                                                                                                            |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Формат**                 | Spotlight coach-marks: затемнение экрана + подсветка реального элемента + подсказка-тултип рядом.                                                                  |
| **Рендер «дырки»**         | Без нативной зависимости — затемнение четырьмя `View` вокруг элемента + рамка с `border-radius`. **Без** `react-native-svg`, **без** `expo prebuild` и пересборки. |
| **Триггер первого показа** | Первый заход на дневник, только если закреплена **группа** и есть **хотя бы один предмет** (состояние `DiaryForGroup` с непустым `subjects`).                      |
| **Повтор**                 | Кнопка «Пройти обучение заново» в Настройках (сбрасывает флаг и открывает дневник).                                                                                |
| **Переходы между шагами**  | Комбинация: кнопка «Далее» + тап по самому подсвеченному элементу тоже ведёт дальше.                                                                               |
| **Действия за жестами**    | «Мутить» (long-press) и «Ввести количество» (открывает sheet) — **только объясняем текстом**, ничего не открываем автоматически.                                   |
| **Закрытие/пропуск**       | Кнопка «Пропустить» + крестик «×». Тап по затемнённому фону **не** закрывает.                                                                                      |
| **Off-screen элементы**    | Автоскролл `FlatList` к элементу перед подсветкой.                                                                                                                 |
| **Полиш**                  | Плавный переход рамки между шагами + лёгкая пульсация (reanimated) + хаптика на смене шага.                                                                        |
| **Состав шагов**           | Все 8 шагов, порядок «сверху вниз».                                                                                                                                |

## 1. Шаги обучалки (порядок «сверху вниз»)

| #   | key            | Цель подсветки                             | Смысл подсказки                                                            |
| --- | -------------- | ------------------------------------------ | -------------------------------------------------------------------------- |
| 1   | `welcome`      | — (по центру, без подсветки)               | «Это твой дневник — веди задания по предметам».                            |
| 2   | `streak`       | `StreakBadge` (шапка, справа)              | Огонёк/стрик: выполняй задания каждый день, чтобы не гас.                  |
| 3   | `planner`      | Левая колонка `DiaryStats` (планер)        | Добавляй задачи, тащи для порядка, отмечай ✓.                              |
| 4   | `upcoming`     | Правая колонка `DiaryStats` (ближайшие)    | Ближайшие сдачи/пары; тап ведёт в расписание.                              |
| 5   | `subjectCard`  | Первая карточка предмета + счётчики        | Тут твои пары; счётчики показывают, сколько заданий осталось по типам пар. |
| 6   | `enterCount`   | Кнопка «ввести количество» / зона карточки | Нажми, чтобы задать количество заданий по предмету.                        |
| 7   | `completeTask` | Сетка заданий (или зона карточки)          | Тап по клетке = выполнено; это растит огонёк.                              |
| 8   | `hideSubject`  | Первая карточка предмета                   | Удерживай карточку → скрыть / сбросить / редактировать.                    |

**Нюанс шагов 6/7.** Карточка показывает **либо** кнопку «ввести количество» (когда счёт не задан), **либо** сетку заданий (когда задан) — одновременно их не бывает. Поэтому цель шага резолвится динамически: если нужного под-элемента нет, шаг подсвечивает всю карточку с соответствующим текстом (сам шаг не пропадает). Резолвинг — в реестре целей (см. §4).

## 2. Архитектура (по MVC проекта)

Новый самодостаточный UI-слой поверх дневника. Бизнес-логики нет — только состояние «показать/шаг/цель» и флаг «просмотрено».

```
src/
  stores/preferences.store.ts      // + флаг diaryOnboardingSeen (persist)
  components/onboarding/
    TutorialContext.tsx            // контекст: реестр целей, текущий шаг, управление
    SpotlightOverlay.tsx           // затемнение (4 View) + рамка + тултип + кнопки + анимация
    steps.ts                       // конфиг 8 шагов (key, i18n-ключи, placement)
    useTutorialTarget.ts           // хук регистрации цели по ключу (measureInWindow)
  views/diary/
    DiaryScreen.tsx                // монтаж провайдера+оверлея, триггер, автоскролл
    StreakBadge.tsx / DiaryStats.tsx / SubjectCard.tsx  // регистрация целей
  views/settings/SettingsScreen.tsx // пункт «Пройти обучение заново»
  i18n/{ru,be,en}.ts               // строки обучалки (namespace onboarding.*)
```

**Реестр целей.** `TutorialContext` хранит `Map<targetKey, () => Promise<Rect>>` (через `measureInWindow`). Подсвечиваемые компоненты регистрируют свой ref хуком `useTutorialTarget(key)`. Оверлей на каждом шаге берёт нужный ключ, измеряет цель, при необходимости просит `FlatList` доскроллить и меряет повторно.

**Автоскролл.** `DiaryScreen` отдаёт в контекст `scrollToTarget(rect)` (обёртка над `FlatList.scrollToOffset`/`scrollToIndex`). Порядок на шаге: measure → если вне вьюпорта, scroll + await + re-measure → показать рамку.

**Затемнение без SVG.** Четыре `Animated.View` (сверху/снизу/слева/справа от `rect`) с `Palette`-совместимым полупрозрачным фоном + один прозрачный `View` с `borderWidth`/`borderRadius` как «рамка-кольцо». Пульсация — анимация `borderColor`/scale кольца через reanimated.

## 3. Definition of Done

- Первый заход на дневник (группа + предметы) → показывается обучалка из 8 шагов.
- «Далее» и тап по элементу ведут вперёд; «Пропустить»/«×» закрывают; фон не закрывает.
- Off-screen элементы (карточки ниже сгиба) — автоскролл перед подсветкой.
- После завершения/пропуска флаг `diaryOnboardingSeen=true`, повторно сам не показывается.
- В Настройках работает «Пройти обучение заново».
- Все строки — в `ru`/`be`/`en`. Ни одного хардкод-цвета/отступа (только `Palette`/`Spacing`/`Radius`).
- Тёмная тема, iOS < 26 и iOS 26 — визуально корректно.
- `npm run typecheck` и `npm run lint` — чисто.

## 4. Пошаговый план (шаг = коммит)

> Формат сообщений: `feat(onboarding): …` / `chore(onboarding): …`. Без co-author, от лица разработчика.

### Шаг 1 — План

- Этот файл `DIARY_ONBOARDING_PLAN.md`.
- Коммит: `docs(onboarding): plan step-by-step diary tutorial`.

### Шаг 2 — Персистентный флаг

- В `preferences.store.ts`: `diaryOnboardingSeen: boolean` (initial `false`), сеттер `setDiaryOnboardingSeen(value)`, добавить в `partialize`.
- Селектор при необходимости.
- Коммит: `feat(onboarding): persist diaryOnboardingSeen flag`.

### Шаг 3 — i18n строки

- В `ru.ts`/`be.ts`/`en.ts` — namespace `onboarding`: заголовки/тексты 8 шагов, кнопки (`next`, `skip`, `done`), пункт настроек (`replay`).
- Коммит: `feat(onboarding): add tutorial i18n strings (ru/be/en)`.

### Шаг 4 — Контекст и конфиг шагов

- `steps.ts` — массив из 8 шагов (key, i18n-ключи, placement подсказки, флаг «без подсветки» для welcome).
- `TutorialContext.tsx` — провайдер: реестр целей, `currentStep`, `start()/next()/skip()/finish()`, `registerTarget/unregister`, `setScroller`.
- `useTutorialTarget.ts` — хук регистрации ref+measure по ключу.
- Коммит: `feat(onboarding): tutorial context, step config and target registry`.

### Шаг 5 — SpotlightOverlay

- `SpotlightOverlay.tsx`: 4 затемняющих `View` + кольцо-рамка + карточка-тултип (заголовок, текст, прогресс-точки, «Далее»/«Пропустить»/«×»).
- Анимация рамки между шагами + пульсация (reanimated), хаптика на смене шага (`hapticLight`).
- Тап по кольцу цели = `next()`.
- Пока монтируется автономно (без реальных целей) для проверки верстки.
- Коммит: `feat(onboarding): spotlight overlay with animated highlight and tooltip`.

### Шаг 6 — Регистрация целей в дневнике

- `StreakBadge` → `streak`; `DiaryStats` планер → `planner`, ближайшие → `upcoming`; `SubjectCard` (только первая видимая) → `subjectCard`/`enterCount`/`completeTask`/`hideSubject` с динамическим резолвом (см. §1).
- Коммит: `feat(onboarding): register tutorial targets on diary widgets`.

### Шаг 7 — Триггер + автоскролл + монтаж на экране

- В `DiaryScreen` (ветка `DiaryForGroup`): обернуть в `TutorialProvider`, смонтировать `SpotlightOverlay`, отдать `scrollToTarget` (реф на `FlatList`).
- Триггер: `!diaryOnboardingSeen && subjects.length > 0` после гидрации — `start()`. На `finish/skip` → `setDiaryOnboardingSeen(true)`.
- Автоскролл к off-screen целям + re-measure.
- Коммит: `feat(onboarding): trigger tutorial on first diary visit with autoscroll`.

### Шаг 8 — Перезапуск из Настроек

- В `SettingsScreen` пункт «Пройти обучение заново»: `setDiaryOnboardingSeen(false)` + `router.push` на дневник.
- Коммит: `feat(onboarding): add replay tutorial entry in settings`.

### Шаг 9 — Полиш и QA

- `typecheck` + `lint`, прогон на симуляторе (светлая/тёмная, мало предметов, длинные названия), правки edge-cases.
- Коммит (если есть правки): `fix(onboarding): QA polish for diary tutorial`.

## 5. Риски / открытые вопросы

- **`measureInWindow` тайминги**: измерять после `InteractionManager`/следующего кадра, иначе нули. Fallback: повторный замер.
- **Нативный таб-бар** (`NativeTabs`): подсветить сам таб «Дневник» из JS нельзя — в обучалке этого шага нет (осознанно).
- **Шаги 6/7 без нужного под-элемента**: динамический резолв цели на всю карточку (см. §1).
- **Мало предметов / скролл**: если целей карточки нет (пустой список отфильтрован триггером), шаги 5–8 не запускаются — триггер требует `subjects.length > 0`.
